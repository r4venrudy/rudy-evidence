# Adoption roadmap

Success means other developers can embed, review and maintain this library without Rudy-specific infrastructure. Stars and download counts alone do not establish that.

1. **Current preview:** C++ core, C ABI, offline CLI, C#/Python bindings, seven bounded adapters, deterministic bundles, comparisons and SARIF.
2. **First adopters:** ship opt-in integrations with Rudy tools, exercise real reports with consent, document incompatible variants, measure cost on representative workloads and collect independent bug reports.
3. **Stabilization:** external security review, structured migration policy, published conformance corpus, sustained cross-platform CI, reproducible release checks and tested distribution recipes. Changes to identity/hash rules require a new contract version.
4. **Broader ecosystem:** registry packages and integration proposals driven by actual consumers, additional bindings, OCSF mappings where semantics can be preserved, signed provenance as a separate explicit protocol.

No current claim of OCSF compliance, production qualification, universal redaction, independent audit or industry-standard status. Do not add hidden telemetry, mandatory hosted services or proprietary infrastructure to the core.
